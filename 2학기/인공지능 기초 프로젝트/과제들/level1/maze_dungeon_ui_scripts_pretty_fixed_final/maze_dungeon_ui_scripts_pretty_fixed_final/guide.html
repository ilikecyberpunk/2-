BFS 설명

Queue를 사용해 가까운 칸부터 탐색합니다.\n이 미로에는 열쇠와 잠긴 문이 있으므로\n(행, 열, 열쇠 보유 여부)를 하나의 상태로 관리합니다.\n따라서 K를 얻기 전에는 L을 지나가지 않습니다.

자동 미로 생성

랜덤 DFS로 통로를 만들고 → S와 E 배치 → S에서 E까지의 실제 경로에 K와 L을 순서대로 배치 → 다른 위치에 T 배치 → Java BFS로 최종 검증
