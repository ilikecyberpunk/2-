[미로 탈출 게임 - 과제 제출본]

============================================================
1. 프로젝트 개요
============================================================
Java로 미로 탈출 게임의 핵심 로직을 구현하고,
HTML/JavaScript로 플레이 화면과 관리 화면을 구성한 프로젝트입니다.

Java  : 미로 처리, 이동, 충돌, 기록, 저장/불러오기, BFS, 미로 생성 등 핵심 로직
HTML  : 게임 화면, 미로 편집기, 기록 화면

실행 환경
- Java JDK 17 이상 권장
- Windows
- 별도 외부 라이브러리 없음

============================================================
2. 실행 방법
============================================================
1) Main.java와 HTML 파일, maze*.txt 파일을 같은 폴더에 둡니다.
2) Windows에서는 run.bat을 실행합니다.
3) 브라우저에서 아래 주소로 접속합니다.

   http://localhost:8080/

※ run.bat은 Java 서버를 먼저 실행한 뒤 약 2초 후 브라우저를 엽니다.
※ 8080 포트가 다른 프로그램에서 사용 중이면 해당 프로그램을 종료한 뒤 다시 실행하세요.

직접 실행할 경우:
   javac Main.java
   java Main

============================================================
3. 과제에서 요청된 기본 기능
============================================================
아래 항목은 과제의 기본 요구사항에 맞춰 구현한 기능입니다.

[미로 데이터]
- 텍스트 파일(.txt)에서 미로를 읽어옵니다.
- 10 x 10 크기의 미로를 사용합니다.
- 서로 다른 3개의 기본 미로(maze1.txt ~ maze3.txt)를 제공합니다.
- 미로 기호를 사용합니다.
  # : 벽
  . : 길
  S : 시작 위치
  E : 출구

[게임 진행]
- W / A / S / D로 플레이어를 이동합니다.
- 벽으로 이동할 수 없습니다.
- 미로의 범위를 벗어날 수 없습니다.
- 이동 횟수를 계산하고 화면에 표시합니다.
- 출구 E에 도착하면 게임이 종료됩니다.
- 게임이 끝난 뒤 기록을 저장합니다.
- 미로별 최소 이동 횟수를 최고 기록으로 관리합니다.
- 게임을 다시 시작하여 반복 플레이할 수 있습니다.

[자동 미로 생성]
- 과제에서 요구되는 자동 미로 생성 기능을 구현했습니다.
- 랜덤 DFS(Randomized Depth-First Search) 방식으로 미로를 생성합니다.
- 생성된 미로는 generated_maze.txt에 저장됩니다.

============================================================
4. 추가 구현한 확장 기능
============================================================
기본 요구사항 외에 게임의 기능과 완성도를 높이기 위해 아래 기능을 추가했습니다.

[열쇠와 잠긴 문]
- K : 열쇠
- L : 잠긴 문
- 열쇠를 획득한 뒤 잠긴 문을 통과할 수 있습니다.

[함정]
- T : 함정
- 함정에 들어가면 시작 위치로 이동합니다.
- 함정 발생 시 이동 횟수에 패널티가 적용됩니다.

[시간 제한 모드]
- 제한 시간 모드를 켜거나 끌 수 있습니다.
- 제한 시간 내에 출구에 도착해야 합니다.

[경로 표시]
- 플레이어가 실제로 지나온 경로를 표시합니다.
- 현재 진행 상황을 시각적으로 확인할 수 있습니다.

[게임 저장 / 이어하기]
- 현재 위치, 이동 횟수, 열쇠 상태 등의 게임 상태를 저장합니다.
- 저장된 상태를 불러와 이어서 플레이할 수 있습니다.

[BFS 최단 경로 탐색]
- BFS(Breadth-First Search)를 이용해 시작점에서 출구까지의 최단 경로를 탐색합니다.
- 탐색 결과를 게임 화면에 시각적으로 표시합니다.
- K/L이 있는 경우 열쇠 상태까지 고려하여 경로를 탐색합니다.

[자동 탈출]
- BFS로 찾은 경로를 이용하여 플레이어가 자동으로 출구까지 이동하도록 구현했습니다.

[사용자 미로 제작]
- 별도의 미로 만들기 화면에서 사용자가 직접 10 x 10 미로를 제작할 수 있습니다.
- 벽, 길, 시작, 출구, 열쇠, 잠긴 문, 함정 등을 선택하여 배치할 수 있습니다.
- 완성한 미로는 Java에서 형식과 연결 가능 여부를 검사한 후 적용합니다.

[미로 유효성 검사]
- 10 x 10 크기인지 검사합니다.
- 허용된 문자만 사용하는지 검사합니다.
- 시작점 S와 출구 E가 각각 정확히 하나인지 검사합니다.
- 바깥 테두리가 벽으로 구성되었는지 검사합니다.
- 출구까지 실제로 이동 가능한지 BFS로 검사합니다.
- 잠긴 문 L이 있을 경우 열쇠 K의 존재 여부도 검사합니다.

5. 화면 구성
============================================================
[게임]
- 실제 미로 플레이
- 이동 횟수 / 시간 / 열쇠 상태 / 게임 상태 표시
- BFS 최단 경로 및 자동 탈출
- 저장 / 불러오기 / 게임 종료

[미로 만들기]
- 클릭으로 미로를 편집할 수 있는 사용자 미로 제작 화면
- 텍스트 형태로도 미로를 입력할 수 있음
- Java 검사 후 사용자 미로 적용

[기록]
- 미로별 최고 기록
- 전체 게임 기록

[발표 자료 참고]
- guide.html은 발표 준비용 참고 자료이며 게임 시각화 화면에서는 연결하지 않습니다.

7. 프로젝트에서 강조할 핵심
============================================================
기본 과제 기능을 구현한 뒤, 다음 확장 기능을 추가하여 게임의 기능성을 높였습니다.

기본 과제
  미로 파일 읽기
      ↓
  플레이어 이동
      ↓
  충돌 및 이동 제한
      ↓
  이동 횟수 / 게임 기록
      ↓
  자동 미로 생성

확장 기능
  K/L 열쇠 시스템
      +
  T 함정
      +
  시간 제한
      +
  경로 표시
      +
  저장 / 불러오기
      +
  BFS 최단 경로
      +
  자동 탈출
      +
  사용자 미로 제작 / 검증

발표에서는 '과제 기본 기능을 먼저 완성하고, 그 위에 추가 기능을 확장했다'는 구조로 설명하면 됩니다.

============================================================
8. 주의사항
============================================================
- 서버 기본 포트는 8080입니다.
- 브라우저 주소는 반드시 http://localhost:8080/ 을 사용하세요.
- 8080 포트가 다른 프로그램에서 사용 중이면 해당 프로그램을 종료한 뒤 다시 실행하세요.
- 게임이 정상적으로 끝나면 records.txt에 기록이 즉시 추가됩니다.
- 서버 시작 시 콘솔에 실제 기록 파일 경로가 표시됩니다.
- 기록 및 저장 파일은 게임 실행 과정에서 내용이 변경될 수 있습니다.
- 실제 제출 점수는 담당 교수님의 세부 평가 기준과 발표 평가에 따라 달라질 수 있습니다.

============================================================
문제 해결
============================================================
[Address already in use]
- 8080 포트를 다른 프로그램이 사용 중이라는 뜻입니다.
- PowerShell에서 다음 명령으로 확인할 수 있습니다.
  netstat -ano | findstr :8080
- 마지막 숫자가 PID입니다. 해당 프로그램을 확인한 후 필요하면 종료하세요.

[localhost 404]
- 반드시 Main.java가 있는 프로젝트 폴더에서 서버를 실행하세요.
- 수정된 Main.java는 프로젝트 폴더의 index.html을 기준으로 HTML을 찾습니다.
- 실행 후 http://localhost:8080/ 으로 접속합니다.
